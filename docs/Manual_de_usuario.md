# Manual de usuario - Sistema de Gestión Académica

Colegio Particular Pitágoras · Versión 1.0 · Año escolar 2026

## Ingreso al sistema (todos los perfiles)

1. Abra el programa, escriba su **usuario** y **contraseña** y pulse **Ingresar**.
2. La primera vez (o si Dirección restableció su clave) el sistema le pedirá crear una contraseña nueva:
   mínimo 8 caracteres, con letras y números.
3. Si se equivoca tres veces seguidas, la cuenta se bloquea 15 minutos.
4. Para cambiar su clave en cualquier momento: menú **Cambiar contraseña**. Para salir: **Cerrar sesión**.

## Perfil Docente

| Menú | Qué hace |
|---|---|
| **Mi carga académica** | Muestra las secciones y áreas que dicta. Seleccione una fila para ver la lista de alumnos. |
| **Calificaciones** | Elija *Periodo*, *Sección* y *Área*. Con doble clic en un estudiante (o el botón **Conclusiones descriptivas**) escriba sus logros, dificultades y recomendaciones por competencia; salen en la libreta. En cada competencia elija AD, A, B o C de la lista. La columna *Área* se calcula sola. Pulse **Guardar calificativos**. Si cambia de sección con datos sin guardar, el sistema le avisa. En un bimestre cerrado la grilla es de solo lectura. |
| **Asistencia** | Elija *Sección*, *Área* y *Fecha*. Todos aparecen como *Asistió*; cambie a *Falta* o *Tardanza* donde corresponda. Para una falta justificada, marque **Justificada**. Pulse **Guardar asistencia**. |
| **Reportes** | Vista previa del acta de calificativos y del resumen de asistencia; genere el **Acta de notas** (PDF o Excel), la **Asistencia** (PDF) o la **Nómina** (PDF). Al terminar puede abrir el archivo o imprimirlo. |

## Perfil Alumno / Apoderado (solo lectura)

| Menú | Qué hace |
|---|---|
| **Calificaciones** | Calificativos de cada competencia y área del bimestre elegido, con el resumen de asistencia. |
| **Asistencia** | Totales de asistencias, faltas, tardanzas y faltas justificadas; detalle por día y área. |
| **Libreta de notas** | Competencias por bimestre, nivel final (bimestre 4), calificativo de cada área, asistencia por bimestre y situación final. El PDF incluye las conclusiones descriptivas. |

## Perfil Director / Coordinador

| Menú | Qué hace |
|---|---|
| **Panel de indicadores** | Asistencia del bimestre, avance del registro de notas por docente, distribución AD/A/B/C por grado, sección o área, y alumnos con C. |
| **Usuarios** | Crear docentes (marcando de 1 a 3 áreas que dicta) y directivos, editar los datos y áreas del docente, activar/desactivar cuentas y restablecer claves. La clave temporal se muestra **una sola vez**: entréguela en persona. |
| **Inscripción de alumnos** | Inscribir (crea la cuenta del apoderado `apo` + DNI), editar datos o sección, retirar o reactivar. |
| **Configuración académica** | Ver grados y secciones, crear secciones; ver áreas y competencias, crear áreas. |
| **Carga académica** | Asignar o reasignar un área de una sección a un docente. Al elegir el área solo aparecen los docentes que la dictan. |
| **Periodos** | Editar fechas de los bimestres, **cerrar** (bloquea notas y asistencia) y **reabrir** (pide motivo). |
| **Reportes y exportación** | Consolidado bimestral por sección (PDF o Excel para el SIAGIE), libreta de un alumno y nómina. |
| **Auditoría y respaldo** | Bitácora de cambios con filtro por fechas y acción; generar una copia de seguridad o restaurarla (escribiendo RESTAURAR). |

## Preguntas frecuentes

- **"No se pudo conectar a la base de datos"**: verifique que el servidor esté encendido y en la misma red.
- **No puedo editar notas**: el bimestre está cerrado; solicite a Dirección su reapertura.
- **Olvidé mi clave**: Dirección puede restablecerla desde *Usuarios*.
